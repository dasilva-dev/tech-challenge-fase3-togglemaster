ROTEIRO COMPLETO DO VÍDEO (NOTA MÁXIMA)
🟢 1. Introdução (20–30s)

“Neste projeto implementamos a aplicação ToggleMaster na AWS utilizando uma arquitetura monolítica, com execução em uma instância EC2 e banco de dados PostgreSQL no Amazon RDS.
Também realizamos a análise da aplicação com base no modelo 12-Factor App e organizamos toda a documentação em um repositório no GitHub.”

🌐 2. Arquitetura AWS (1 min)

👉 Mostre no console:

VPC
subnets
EC2
RDS

Fale:

“Criamos uma VPC dedicada com uma subnet pública para a EC2 e subnets privadas para o RDS.
A aplicação roda na EC2 e o banco fica isolado na rede privada, garantindo segurança.”

🔐 3. Segurança (30–40s)

👉 Mostre:

Security Group da EC2
Security Group do RDS

Fale:

“O acesso ao banco de dados é restrito apenas à instância EC2, através de regras de Security Group, impedindo acesso externo direto ao RDS.”

🖥️ 4. EC2 e RDS (30s)

👉 Mostre:

EC2 → Running
RDS → Available

Fale:

“Aqui podemos ver a instância EC2 em execução e o banco RDS disponível.”
